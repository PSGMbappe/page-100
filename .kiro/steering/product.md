# Page 100 — teletext, resurrected

A web app that brings back 1980s/90s UK TV teletext: blocky full-screen text pages you navigate by typing 3-digit page numbers, now showing live news, weather and football scores.

- Must feel authentic: 40×25 character grid, 8 teletext colours, chunky block graphics, double-height headlines, the page-number header with a ticking clock.
- Navigation like the old TV remote: type a page number (e.g. 302), use the four coloured "Fastext" links, flick through sub-pages.
- Fun first, but genuinely useful: quick, readable headlines, weather and scores.
- Hackathon: Kiroween 2026, category "Resurrection" (bring dead tech back to life with today's tech).
- Do not use broadcaster brand names (e.g. real teletext service names or channel logos). The service is called "PAGE 100".
